# GB/Z 185-2026 — 人工智能 智能体互联（7部分）

## 基本信息

- **官方名称**: GB/Z 185-2026《人工智能 智能体互联》系列国家标准（指导性技术文件）
- **英文标准名称**: Artificial intelligence — Agent interconnection
- **发布时间**: 2026年5月22日（国家标准委公告），2026年7月3日正式发布解读
- **发布机构**: 国家市场监督管理总局、国家标准化管理委员会
- **主管部门**: 国家标准委
- **研制单位**: 中国电子技术标准化研究院牵头，联合北京邮电大学、华为、清华大学、阿里云、中国移动、中兴通讯、中国联通、中国电信等70余家产学研用单位

## 核心内容

### 总体架构（第1部分）

定义智能体互联世界的**五大概念域**：

| 概念域 | 职责 | 企业类比 |
|--------|------|----------|
| **用户域** | 任务发起和结果接收 | 员工、客户、部门 |
| **智能体域** | Agent 身份维护、描述维护、互联鉴权、交互和工具访问 | 各类 AI 员工 |
| **管理服务域** | 身份管理、凭证、鉴别服务 | 人事、门禁、权限中心 |
| **互联服务域** | 描述管理、智能体发现和消息分发 | 通讯录、应用市场、协作平台 |
| **资源访问域** | 工具、接口、系统、数据库 | ERP、CRM、OA、知识库 |

### 身份码（第2部分）

- 每个 Agent 须拥有**唯一的身份编码**
- 采用分层标识体系
- 一个身份码仅对应一个智能体
- 支持跨组织、跨平台的 Agent 身份识别

### 身份管理（第3部分）

Agent 的**生命周期管理**——从创建、注册、授权、运营到注销：
- 身份注册与验证
- 权限分配与回收
- **行为审计与追溯**
- 异常锁定与紧急注销

### 能力描述（第4部分）

- 智能体能力描述及其注册、发布和变更
- 统一的能力描述格式
- 支持能力发现和匹配

### 发现流程（第5部分）

- 智能体发现机制
- 能力匹配算法
- 服务注册中心

### 智能体交互（第6部分）

- 点对点、群组、混合等交互模式
- 消息格式规范
- 交互流程控制
- 错误处理机制

### 工具调用（第7部分）

- 外部工具调用的架构
- 调用流程规范
- 数据格式标准
- 安全控制

## 与审计日志/决策记录/AI Agent 行为相关的要求

### 审计日志要求

- **行为审计与追溯**: 身份管理（第3部分）明确要求对 Agent 行为进行审计
- **日志审计**: 第7部分（安全要求）包括日志审计要求
- **操作记录**: 工具调用（第7部分）需要记录所有工具访问
- **身份验证日志**: 双向身份鉴别过程需要记录

### 决策记录要求

- **授权记录**: 谁授权 Agent 做事需要记录责任主体
- **权限边界**: Agent 能访问什么系统需要明确记录
- **调用链**: Agent 调用了什么工具需要可追溯
- **协作记录**: 多 Agent 协作的任务分解、分工、结果合并需要记录

### AI Agent 行为相关

- **身份唯一性**: 每个 Agent 有唯一身份码，从源头保障可追溯性
- **双向鉴别**: 请求 Agent 与服务 Agent 完成双向身份鉴别后方可交互
- **访问控制**: 依据身份凭证和鉴别结果实施访问控制与互联鉴权
- **权限管理**: 权限分配与回收的全生命周期管理
- **异常处理**: 异常锁定与紧急注销机制
- **可信身份**: 将可信身份作为互联基础

## 与国际标准比较

| 维度 | GB/Z 185-2026（中国） | A2A（Google） | MCP（Anthropic） |
|------|------------------------|---------------|------------------|
| **性质** | **国家标准**（推荐性） | 厂商标准 | 开源协议 |
| **范围** | 智能体全生命周期（身份→协作→安全） | Agent 间通信协议 | 工具调用协议 |
| **身份管理** | ✅ **完整体系** | ❌ 未覆盖 | ❌ 未覆盖 |
| **凭证管理** | ✅ **完整体系** | ❌ | ❌ |
| **安全要求** | ✅ **专用章节** | 部分 | 部分 |
| **组织治理** | ✅ **企业级管理架构** | ❌ | ❌ |
| **参与方** | 70+ 产学研单位 | Google + 合作伙伴 | Anthropic |

**核心差异**: GB/Z 185 不仅仅是通信协议，而是从企业治理视角出发，解决 Agent 的**身份、认证、权限、审计、安全**等全链路问题。

## 适用行业

- **所有使用 AI Agent 的行业**，包括:
  - 企业运营
  - 工业制造
  - 城市治理
  - 民生服务
  - 具身智能机器人
  - 办公自动化
  - 政务服务

## 处罚措施

- GB/Z 185 为**指导性技术文件**，非强制性标准
- 不具有直接法律约束力
- 但可作为:
  - 行业监管的参考依据
  - 政府采购的技术要求
  - 企业合规的最佳实践
  - 行业认证的评估基准

## 产业意义

1. **从演示走向规模化**: 为 Agent 落地企业系统提供底层合规框架
2. **多厂商互通**: 不同厂商的 Agent 可以在同一标准下协作
3. **安全合规基础**: 身份管理+凭证管理+安全要求，让企业敢把 Agent 接入核心系统
4. **全球首个国家级 Agent 标准**: 在 AI Agent 标准化领域走在前列
