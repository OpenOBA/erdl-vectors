# 中国信通院「可信 AI 智能体评估体系 2.0」(2026)

## 基本信息

- **官方名称**: 中国信通院可信 AI 智能体评估体系 2.0
- **发布时间**: 2026年4月15日
- **发布机构**: 中国信息通信研究院（CAICT）人工智能研究所
- **性质**: 行业评估体系（非强制性，但具有行业权威性）
- **官方来源**: 中国信通院 CAICT 公众号、中国人工智能产业发展联盟 (AIIA)
- **前期基础**: 可信 AI 智能体评估体系 1.0（覆盖通用智能体、场景智能体、行业智能体）

## 核心内容

### 概述

可信 AI 智能体评估体系 2.0 是在 1.0 基础上的重大升级，从面向通用/场景/行业智能体的评估，升级为**面向企业级智能体的全链路评估体系**。体系构建全生命周期、多层次、可量化的综合评价框架，全面保障智能体在复杂开放环境下**可信可控、稳定高效、合规安全**。

### 八大评估维度

| # | 维度 | 重点关注 |
|---|------|----------|
| 1 | **智能体基础设施** | 运行环境、硬件资源适配、异构兼容、弹性扩展 |
| 2 | **智能体数据资源** | 数据开发、数据工程、DataOps 能力 |
| 3 | **智能体核心组件** | 协作协议、RAG、Skills、编排能力 |
| 4 | **智能体平台支撑** | 开发、测试、运营、优化全生命周期的平台与工程能力 |
| 5 | **智能体关键能力** | 感知、决策、生成、交互、多智能体协同、多模态智能体 |
| 6 | **智能体典型应用** | 个人应用（智能助手）、企业级应用（客服、营销）、行业应用（金融、工业、教育） |
| 7 | **智能体运营管理** | 运营、运维与管理制度与能力 |
| 8 | **智能体价值评价** | 业务价值、服务质量、应用效能、功能性能、应用成熟度 |

### 各维度详解

#### 1. 智能体基础设施

- 智能体运行环境的稳定性和可靠性
- 硬件资源适配能力
- 异构系统兼容性
- 弹性扩展能力
- 资源利用效率

#### 2. 智能体数据资源

- 面向智能体的数据开发流程
- 数据工程能力（数据清洗、标注、增强）
- DataOps 能力（数据运营和持续优化）
- 数据质量和完整性保障

#### 3. 智能体核心组件

- **协作协议**: Agent 间通信和协作的标准化
- **RAG (Retrieval-Augmented Generation)**: 知识检索增强生成能力
- **Skills**: 技能库的丰富度和可组合性
- **编排 (Orchestration)**: 多组件、多 Agent 的编排调度能力

#### 4. 智能体平台支撑

- 开发平台的成熟度和易用性
- 测试框架的覆盖度和自动化程度
- 运营平台的监控和管理能力
- 优化工具的性能和效果

#### 5. 智能体关键能力

- **感知能力**: 多模态输入理解和环境感知
- **决策能力**: 复杂场景下的自主决策
- **生成能力**: 高质量内容生成
- **交互能力**: 自然语言交互和多轮对话
- **多智能体协同**: 多 Agent 协作完成任务
- **多模态智能体**: 跨模态理解和生成

#### 6. 智能体典型应用

- **个人应用**: 智能助手、个人助理
- **企业级应用**: 客服、营销、流程自动化
- **行业应用**: 金融风控、工业质检、教育辅导

#### 7. 智能体运营管理

- 运营管理制度和流程
- 运维监控和故障处理
- 性能优化和版本迭代
- 安全管理和合规保障

#### 8. 智能体价值评价

- 业务价值量化
- 服务质量指标（SLA）
- 应用效能评估
- 功能性能测试
- 应用成熟度评价

## 与审计日志/决策记录/AI Agent 行为相关的要求

| 维度 | 审计相关 |
|------|----------|

| **平台支撑** | 开发测试日志、部署记录 |
| **关键能力** | Agent 决策过程记录、交互日志 |

### 决策记录要求

| 维度 | 决策相关 |
|------|----------|
| **关键能力** | 自主决策过程的记录和可解释性 |
| **核心组件** | 编排决策的记录和可追溯性 |
| **典型应用** | 应用场景决策的评估和记录 |
| **价值评价** | 业务决策的效果评估和记录 |

### AI Agent 行为相关

| 维度 | Agent 行为相关 |
|------|----------------|
| **关键能力** | 感知、决策、生成、交互行为的评估 |
| **核心组件** | 协作协议、编排行为的标准化评估 |
| **运营管理** | Agent 行为监控、异常检测和处理 |
| **价值评价** | Agent 行为效果的业务价值评估 |

### 可信可控要求

体系强调智能体在复杂开放环境下的四个核心特性:

| 特性 | 说明 |
|------|------|
| **可信** | 行为可预期、结果可验证、过程可审计 |
| **可控** | 人工监督到位、异常可干预、权限有边界 |
| **稳定** | 性能可保障、故障可恢复、服务可持续 |
| **安全** | 数据有保护、行为有规范、风险可管控 |

## 适用行业

- **企业级智能体应用**，覆盖:
  - 软件开发（代码 Agent）
  - 金融服务（风控、客服、营销 Agent）
  - 智能制造（质检、调度 Agent）
  - 教育（辅导 Agent）
  - 政务（服务 Agent）
  - 医疗（辅助诊断 Agent）

## 评估服务

### 评估历史

- **评估体系 1.0**: 覆盖通用智能体、场景智能体、行业智能体
- **评估体系 2.0**: 面向企业级智能体的全链路评估
- **累计服务**: 50余家单位的智能体专项评估

### 评估用途

- **技术选型**: 为企业选择智能体产品提供科学依据
- **项目验收**: 为智能体项目验收提供标准化支撑
- **行业监管**: 为监管部门提供评估基准
- **规模化落地**: 为智能体规模化应用提供可信保障

## 组织生态

- **中国人工智能产业发展联盟 (AIIA)**: 联合业界百余家单位
- **智能体创新与应用委员会**: 在 AIIA 下设立
- **活动**: 案例征集、技术沙龙、评估测试

## 处罚措施

- **评估体系本身不具有法律强制力**
- 但作为行业权威评估:
  - 影响企业技术选型和项目验收
  - 作为行业监管的参考依据
  - 影响市场声誉和竞争力
  - 可作为政府采购的评估标准
