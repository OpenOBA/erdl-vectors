### Principles

- **Measurements, not endorsements**: the registry records facts; no certification, no endorsement, no guarantee.
- **Spec neutrality**: the value of an implementation is determined by its degree of conformance to the spec text, independent of author or affiliation.
- **No answers file**: submitters MUST implement the JCS canonicalizer themselves; the answers file is never exposed to runners.
- **Clean-room preferred**: confirming that no ERDL SDK is importable before verification makes the independence stronger.
- **Canary resident**: K01 catches defective implementations that "skip independent recompute" (delete the entire audit instead of only audit.hash).
