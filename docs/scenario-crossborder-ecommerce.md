## 一、跨境电商场景的命题

> 证明：跨组织、跨语言，同一笔跨境订单（货值/目的国/币种/时点）执行合规规则后，**关税/VAT/币种换算的裁决与金额一致**。

## 二、语义分叉点（权威锚点）

锚定 ISO 4217、欧盟 IOSS/OSS、各国 de minimis 规则。

### 分叉点 1：de minimis 关税阈值（分国别，法域分层）
- 美国 $800、欧盟 €150（**2026-07-01 起取消**）、中国 RMB 150、印尼 $3、泰国 THB 1（≈取消）、印度 $0（无 de minimis）
- 内核可表达：比较 + 法域字段 + 分层

### 分叉点 2：VAT/GST 税率（分国别）
- 欧盟标准税率 17%（卢森堡）～ 27%（匈牙利）；IOSS/OSS 机制
- 内核可表达：in + 税率表 + 分层

### 分叉点 3：币种换算精度（ISO 4217 minor unit exponent）—— **内核硬缺口，PASS**
- USD/EUR/GBP=2 位；JPY/KRW/VND/CLP/ISK=0 位；KWD/BHD/OMR=3 位；CLF=4 位
- ERDL 现有 E2 = 统一 scale=14 + half-even，**无「按币种动态小数位」概念** → PASS

## 三、第一批跨境电商向量设计（4 类）

### 类型 A：de minimis 关税阈值（法域分层，最核心）
> `货值 ≤ 目的国 de minimis 阈值 → 免关税；> 阈值 → 计关税`
- 覆盖：各国阈值 × 恰好边界（美国 $800 / 欧盟 €150 / 中国 RMB 150）

### 类型 B：VAT/GST 税率（分国别）
> `目的国 ∈ 欧盟 → 按该国标准税率计 VAT`

### 类型 C：币种换算（仅现有 half-even 部分，ISO 4217 小数位 PASS）
> `金额 × 汇率`（scale=14 half-even）

### 类型 D：跨境合规多条件组合
> `跨境 且 货值超阈值 且 目的国 ∈ 敏感名单 → 人工复核`

## 四、跨行业共性（重要，供统一模板设计）

三个行业（金融/医疗/跨境电商）反复暴露同一个分歧点结构：

> **「阈值 + 法域分层」是「规则即代码」跨语言一致性的头号分歧源。**

- 医疗 GDPR §8：同意年龄 13/14/15/16（全局默认 16 + 成员国下调）
- 跨境 de minimis：关税阈值（美国 $800 / 欧盟 €150 / 中国 RMB 150）
- 跨境 VAT：税率 17%–27%

三者同构：**一个全局默认值 + 各国覆盖层，边界值必须精确裁决。**

→ ERDL 三级立法分层（全局 + 法域覆盖，"命中即拦、冲突交用户"）正是为这个模式设计。后续三个行业的场景向量，可能收敛到**同一个「法域分层向量模板」**。
