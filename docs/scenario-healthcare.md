## 二、语义分叉点（权威锚点）

锚定 GDPR（§7/§8/§9/§33）、HIPAA（45 CFR Part 164）。

### 核心发现：GDPR §8 数字同意年龄 = 「阈值 + 法域分层」的确定性考场

GDPR §8：数字服务直接向儿童提供时，同意年龄**默认 16**，成员国可下调到 **13–16**：

| 阈值 | 国家 |
|---|---|
| 13 | 比利时、捷克、丹麦、芬兰、爱尔兰、拉脱维亚、波兰、葡萄牙、瑞典、英国 |
| 14 | 奥地利、保加利亚、塞浦路斯、意大利、立陶宛、西班牙 |
| 15 | 法国、希腊、斯洛文尼亚 |
| 16（默认） | 德国、匈牙利、卢森堡、荷兰、罗马尼亚、斯洛伐克 |

→ 同一个 14 岁用户，爱尔兰可自主同意、德国须父母授权。**这是 ERDL 三级立法分层（全局 + 法域覆盖）的天然用例。**

## 三、第一批医疗向量设计（4 类）

### 类型 A：GDPR §8 数字同意年龄（法域分层，最核心）
> `年龄 < 该国数字同意年龄 且 依赖同意为合法依据 → 需父母授权`
- 覆盖：13/14/15/16 × 恰好等于边界；全局 16 + 成员国覆盖

### 类型 B：数据泄露通知时限（GDPR 72h vs HIPAA 60天）
> `泄露发现时间 + 72h 未通知 → DENY`
- 覆盖：恰好 72h / 71h59m / 72h1s 边界、跨时区 UTC

### 类型 C：HIPAA 未成年人个人代表
> `未脱管未成年人 且 服务 ∈ 需父母同意 → 父母/监护人代理`

### 类型 D：GDPR §9 敏感数据分类
> `数据 ∈ {健康,基因,生物识别,性取向,种族} → 特殊类别，更高同意标准`

## 四、医疗 vs 金融的差异

- 金融分叉点主要在**数值**（金额舍入、日期惯例）——分歧=钱；
- 医疗分叉点主要在**裁决**（阈值 + 法域分层 + 时限）——分歧=合规重罚（GDPR 上限 4% 营收）。
